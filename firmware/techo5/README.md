# Voz integrada sobre TECHO5

Parche experimental sobre TECHO5 v1.2.22, commit `8f39f704319b802d7fcb094518b7563e2b660a1c`. [Fuentes y construcción upstream](https://github.com/HuskerMinion/techo5/blob/v1.2.22/docs/building.md). Licencia original en [LICENSE.upstream](LICENSE.upstream).

Compone una capa nativa con borde estático, pregunta, respuesta, cierre táctil y scroll sobre el dashboard Streamed. Reutiliza el render mientras no cambien fase, texto o desplazamiento. Conserva prioridad de llamadas, alarmas y otras pantallas. El prototipo HTML de `test/echo-voz` permite revisar el aspecto; no sustituye la implementación nativa.

1. `tools/build_echo_voice.sh` obtiene el commit fijado, comprueba el commit, aplica el parche, ejecuta las suites seleccionadas y compila para ARMv7 en Docker Go 1.26. Usa el fondo sintético de `test/echo-v5/casa.png`, generado por la prueba visual. Los modelos, fuentes clonadas y binarios de trabajo están ignorados. La construcción escribe también un manifiesto ignorado con commit del proyecto y hashes del parche y binario; el despliegue rechaza un binario que no coincida con el checkout etiquetado.
2. Antes de desplegar, verifica compatibilidad de tu dispositivo y define `ECHO_EXPECTED_SHA256` con el hash de su ejecutable comprobado, `ECHO_HOST` y `SSH_KEY`. El hash no certifica compatibilidad por sí solo; no hay un hash privado de una instalación como valor predeterminado. `tools/deploy.sh --version v0.1.0 --echo-voice` hace copia de HA y del binario anterior, verifica la copia y realiza un bind mount temporal; reinicia solo el proceso TECHO5.
3. `tools/rollback.sh --echo-voice` retira el montaje. Un reinicio del Echo también recupera su ejecutable persistente. La instalación permanente requiere trabajo adicional y validación física de micrófono, audio, texto, cierre y scroll. Las pruebas locales no validan hardware ni la suite global de TFLite.
